# IGRIS Business Pulse

A research initiative by **IGRIS Technologies** — a static, no-build frontend (HTML, Tailwind CDN, vanilla JS) that surveys Nigerian businesses about their real operational problems before IGRIS builds more technology around them.

Brand reference: [igris-tech.vercel.app](https://igris-tech.vercel.app)

## Structure

```
/index.html            homepage
/survey.html            one-question-at-a-time survey
/thank-you.html         post-submit confirmation + personalized recommendation + share loop
/admin.html              password-gated research dashboard (not linked publicly)
/assets/igris-logo.png  the real IGRIS mark, trimmed + transparent background
/css/styles.css          design tokens + base styles (shared by every page)
/js/main.js              homepage interactions (menu, reveal-on-scroll, number count-up)
/js/survey.js            survey engine (state, validation, transitions, submission)
/js/admin.js             admin login + dashboard + sortable responses table
/js/data-store.js        storage layer (API first, localStorage fallback)
/js/api.js               central API base URL config
/js/auth.js              admin token / session helpers
/js/api-client.js        fetch wrappers for FastAPI endpoints
/js/recommendation.js    recommendation engine — maps answers to a relevant IGRIS service
/data/questions.js       the 10 survey questions — single source of truth
/API_CONTRACT.md         frontend ↔ FastAPI interface documentation
```

## The logo

`/assets/igris-logo.png` is the mark you sent, auto-cropped to its content and given a transparent background so it drops cleanly onto any section. It's icon-only (no wordmark baked in), so every page pairs it with an "IGRIS" text lockup next to it — same pattern your live site uses with "IGRIS TECH" next to the mark.

If you'd rather use a vector version, drop in `assets/igris-logo.svg` and swap the four `<img src="assets/igris-logo.png">` references (one each in `index.html` ×2, `survey.html`, `thank-you.html`, `admin.html` ×2) to point at it — everything else about the layout stays the same.

## Running locally (development)

This project now uses Vite + React for local development. The project still preserves the original styles and markup while running under a modern dev server.

Install dependencies and start the dev server:

```bash
npm install
./generate-env-config.sh   # (optional) generate env-config.js from .env
npm run dev
```

Vite serves the site on `http://localhost:8000` by default; if that port is in use Vite will pick the next available port and print the URL in the terminal.

To build and preview a production bundle:

```bash
npm run build
npm run preview
```

Environment notes

- `env-config.js` (generated by `./generate-env-config.sh`) exposes `window.__ENV.API_BASE_URL` used by the client to reach the backend. Run the generator after editing `.env` and before starting the dev server so the runtime configuration is available in the browser.

Removed temporary dev server

- The previous `dev_server.py` Python server was a temporary shim to support clean routes; it has been removed. Clean-route handling is now implemented in `vite.config.js` so the Vite dev server will correctly serve extensionless routes like `/survey` and `/thank-you` during development.

## Admin access

`/admin.html` isn't linked from public navigation. It's gated by a password stored in plain sight in `js/admin.js` (`ADMIN_PROTOTYPE_PASSWORD`) — **a prototype gate only, not real authentication**. It keeps the page from being wide open by accident, but anyone who opens devtools can read the password. Replace it with real server-side auth (`POST /api/v1/admin/login`) before collecting production data. Login state lives in `sessionStorage`, so it clears when the tab closes.

Default prototype password: `igris-research-2026` — change this before sharing the link with anyone.

## Data & storage

The data layer (`js/data-store.js`) tries the FastAPI backend first (via `js/api-client.js`).
If the backend is unavailable or `API_CONFIG.BASE_URL` is empty, it falls back to browser `localStorage`.
See `API_CONTRACT.md` for the full interface.

Change the API base URL in one place:

```js
// js/api.js
const API_CONFIG = {
  BASE_URL: "http://localhost:8000/api/v1"   // or production URL
};
```

Internal response schema (frontend):

```js
{
  id: "BP-2026-000001",
  createdAt: ISOString,
  businessType, customerChannels, biggestChallenge, timeConsumingTask,
  orderManagement, paymentTracking, technologyUsed, digitalBarriers,
  desiredImprovement: string,
  contactPermission: "Yes" | "No",
  contact: string | null
}
```

Because it's `localStorage`, responses only exist in the browser/device that submitted them — there's no shared backend yet, so the admin dashboard on your machine won't see a response someone filled out on their phone. See "Moving to a real backend" below.

### Backend connection

The API client and data-store already implement the FastAPI seams.
Set `API_CONFIG.BASE_URL` in `js/api.js` to your backend. When the backend is down or unreachable, the app continues to work against localStorage so frontend and backend can be developed independently.

## Recommendation engine

`js/recommendation.js` is pure logic (no DOM) — `getRecommendation(answers)` takes a completed response and returns one relevant IGRIS service (Web Development, Custom Software, Automation, AI Solutions, or a broader "start a conversation" for multi-problem responses), or `null` if nothing fits confidently. All links point at the real `igris-tech.vercel.app` service pages. Edit the `CHALLENGE_TO_CATEGORY` map or `RECOMMENDATIONS` object to change the logic — `thank-you.html` just renders whatever it returns.

## Design system

Colors, spacing, and motion rules live in `css/styles.css` as CSS custom properties (`--ink`, `--paper`, `--off-white`, `--charcoal`, `--muted`, `--line`). Tailwind (via CDN) handles layout utilities.

**Note on the Tailwind CDN:** `cdn.tailwindcss.com` (the "Play CDN") is flagged by Tailwind itself as dev-only, not for production. Fine for this prototype; swap for a compiled Tailwind build before this goes live in front of real users.
